## 📌 Sobre o Projeto

Portfólio pessoal desenvolvido para apresentar minha trajetória como desenvolvedora Full Stack, exibindo projetos reais consumidos diretamente da API do GitHub, com design responsivo, carrossel interativo e formulário de contato funcional.


---

## ✨ Funcionalidades

- 🔗 **Integração com a API do GitHub** — projetos buscados dinamicamente, sempre atualizados
- 🎠 **Carrossel com Swiper.js** — navegação suave e responsiva entre os projetos
- 📬 **Formulário de contato funcional** — envio de e-mail diretamente pelo site
- 📱 **Design responsivo** — adaptado para mobile, tablet e desktop
- 🎨 **UI moderna e animada** — experiência visual agradável e fluida
